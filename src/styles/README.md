# Folder Styles

Folder ini berisi semua file CSS untuk website Explore Indonesia.

## Struktur File:

- **index.css** - Styling untuk halaman Home/Landing
- **product.css** - Styling untuk halaman Product (Speedboat & Rent Car)
- **gallery.css** - Styling untuk halaman Gallery
- **about.css** - Styling untuk halaman About
- **contact.css** - Styling untuk halaman Contact

## Cara Menggunakan:

File CSS ini akan di-import secara otomatis di setiap halaman Astro menggunakan tag `<link>`.

## Catatan untuk Developer:

- Jangan menghapus file CSS tanpa memperbarui halaman yang menggunakannya
- Semua CSS sudah responsive untuk mobile, tablet, dan desktop
- Gunakan media queries yang sudah ada untuk menjaga konsistensi
